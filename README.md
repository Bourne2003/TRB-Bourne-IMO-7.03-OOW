# สมุดบันทึกการฝึกนายประจำเรือฝ่ายเดินเรือ (OOW Training Notebook)

### IMO Model Course 7.03 — STCW Code Section A-II/1 · Officer in Charge of a Navigational Watch (ships of 500 GT or more)

**บันทึกและเรียบเรียงโดย TIRAPHONG NANTAPAN**

---

สมุดเล่มนี้คือบันทึกการเรียนและการฝึกของผมสำหรับประกาศนียบัตรนายประจำเรือฝ่ายเดินเรือ (OOW) เขียนเป็นภาษาไทยและวงเล็บศัพท์อังกฤษไว้ เพราะบนเรือใช้ภาษาอังกฤษทั้งหมด หัวข้อเรียงตามตารางสมรรถนะ STCW A-II/1 และ IMO Model Course 7.03 **ครบทั้ง 3 Function ไม่ข้ามหัวข้อ** แต่ละบทมี

- ข้อกำหนดสมรรถนะ (competence) ความรู้ (KUP) และเกณฑ์ประเมินของ STCW ที่หัวบท
- คำอธิบายตั้งแต่พื้นฐานจนถึงระดับที่ใช้ตอบสอบปากเปล่าและสัมภาษณ์งานได้
- ภาพประกอบ (SVG) ในจุดที่ภาพช่วยให้เข้าใจเร็วกว่าตัวหนังสือ
- **ตัวอย่างจำลอง** — สถานการณ์และการคำนวณที่สร้างขึ้นให้ใกล้ของจริง (ตัวเลขใช้ฝึกเท่านั้น)
- **คำถามสอบปากเปล่า / สัมภาษณ์** พร้อมแนวตอบท้ายบท

> **ข้อควรระวัง** — นี่คือบันทึกเพื่อการศึกษา ไม่ใช่สิ่งพิมพ์ทางการ การทำงานจริงต้องใช้ฉบับปัจจุบันของอนุสัญญา ประมวลข้อบังคับ แผนที่ และสิ่งพิมพ์ที่แก้ไขแล้ว รวมถึง SMS ของบริษัทและข้อกำหนดของรัฐเจ้าของธงเสมอ เนื้อหาเขียนให้สอดคล้องและไม่ขัดกับ STCW — ตัวเลข เลขข้อมติ และวันมีผลบังคับในสมุดนี้ตรวจทานล่าสุดเมื่อ ต.ค. 2026 (ข้อกำหนดที่ยังไม่มีผล เช่น pilot transfer arrangements 2028 หรือการแก้ไข MLC ปี 2025 ระบุไว้ว่าเป็นวันที่คาดว่าจะมีผล)


**สคริปต์ใน `tools/`**

- `gen_*.py` — สร้างภาพประกอบ SVG ของแต่ละบท (เช่น `python3 tools/gen_safety_svgs.py`)
- `validate_svgs.py` — ตรวจว่าไฟล์ SVG ทุกไฟล์เป็น XML ที่ถูกต้อง
- `build_question_bank.py` — รวบรวมคำถามท้ายบทใหม่เป็นภาคผนวก ข (รันทุกครั้งที่แก้คำถามในบท) — ส่วนหัว (วิธีสอบ ตารางตัวเลขที่ต้องจำ) และส่วนท้าย (คำถามสถานการณ์ คำถามสัมภาษณ์) แก้ที่ `tools/qbank/head.md` และ `tools/qbank/tail.md` ไม่ใช่ที่ไฟล์ภาคผนวก ข โดยตรง
- `build_pdf.py` — รวมทุกบทและภาคผนวกเป็น PDF เล่มเดียว (Markdown → HTML → PDF ผ่าน Playwright ฟอนต์ไทยอยู่ใน `tools/pdf/fonts`)
  - ต้องมี `pip install markdown-it-py mdit-py-plugins pypdf` และ Playwright (Chromium) — ใช้: `python3 tools/build_pdf.py` ได้ไฟล์ `pdf/OOW-Training-Notebook-IMO-7.03-TIRAPHONG-NANTAPAN.pdf` (ปก สารบัญพร้อมเลขหน้า bookmark ทุกบท ภาพเวกเตอร์)
- `build_site.py` — สร้างเว็บหนังสือออนไลน์ (GitHub Pages) ลงโฟลเดอร์ `_site/` และตรวจลิงก์ ภาพ และคำถามทุกข้อ — แม่แบบ CSS/JS และฟอนต์ Trirong (SIL OFL) อยู่ใน `tools/site` ดูหัวข้อ "อ่านออนไลน์" ด้านบน
