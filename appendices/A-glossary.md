# ภาคผนวก ก — อภิธานศัพท์ (Glossary)

> สมุดบันทึกการฝึก OOW · TIRAPHONG NANTAPAN
> ศัพท์และอักษรย่อที่ใช้ในสมุดเล่มนี้ เรียงตามตัวอักษรภาษาอังกฤษ พร้อมความหมายภาษาไทยแบบที่ใช้จริงบนเรือ และบทที่อธิบายรายละเอียด — ไม่ใช่พจนานุกรมทางการ ถ้าต้องการนิยามตามกฎหมาย ให้ดูนิยามในอนุสัญญา/ประมวลข้อบังคับนั้นโดยตรง

## A

| ศัพท์ | ความหมาย | บท |
|---|---|---|
| Abaft | ไปทางท้ายเรือเมื่อเทียบกับจุดหนึ่ง เช่น abaft the beam = เลยแนวขวางลำไปทางท้าย | 1.2.1-A |
| Abandon ship | การสละเรือ/ละทิ้งเรือ — ทำตามคำสั่งนายเรือเท่านั้น | 3.4, 3.8 |
| Abort point | จุดสุดท้ายในแผนการเดินทางที่ยังยกเลิกการเข้าช่องแคบ/ท่าได้อย่างปลอดภัย | 1.1.0 |
| Accommodation ladder | บันไดข้างเรือแบบปรับมุมได้ ใช้ขึ้นลงเรือที่ท่า หรือใช้ร่วมกับบันไดนำร่อง (SOLAS II-1/3-9, MSC.1/Circ.1331/Rev.1) | 1.2.1-B, 3.8 |
| Air pressure test (immersion suit) | การทดสอบลมที่รอยต่อและซิปของ immersion suit — ทุกชุดไม่เกินทุก 3 ปี ถี่ขึ้นเมื่ออายุเกิน 10 ปี (MSC/Circ.1114) | 3.4, 3.8 |
| AIS (Automatic Identification System) | ระบบแสดงตนอัตโนมัติ ส่งข้อมูลเรือ (ชื่อ ตำแหน่ง เข็ม ความเร็ว) ทาง VHF | 1.1.3, 1.2.1-B |
| Alarm, general emergency | สัญญาณฉุกเฉินทั่วไป สั้น 7 ครั้งหรือมากกว่า ตามด้วยยาว 1 ครั้ง | 3.4, 3.8 |
| ALARP (As Low As Reasonably Practicable) | หลักลดความเสี่ยงให้ต่ำที่สุดเท่าที่ทำได้อย่างสมเหตุสมผล | 3.7, 3.8 |
| Altitude (celestial) | มุมสูงของเทห์ฟ้าเหนือขอบฟ้า วัดด้วย sextant แล้วแก้ค่า | 1.1.1 |
| Amplitude | มุมราบของดวงอาทิตย์ขณะขึ้น/ตกวัดจากทิศตะวันออก/ตะวันตก ใช้ตรวจความผิดของเข็มทิศ | 1.1.1, 1.1.5 |
| Anchor watch | การเข้ายามขณะทอดสมอ ตรวจว่าสมอไม่ลาก | 1.2.1-B, 1.9 |
| Angle of loll | มุมเอียงค้างของเรือที่ GM เริ่มต้นเป็นลบ — ห้ามแก้ด้วยการถ่ายน้ำหนักข้ามลำ | 3.2.1 |
| Angle of vanishing stability | มุมเอียงที่ GZ เป็นศูนย์ เกินกว่านี้เรือคว่ำ | 3.2.1 |
| ARPA (Automatic Radar Plotting Aid) | อุปกรณ์ติดตามและคำนวณ CPA/TCPA ของเป้าเรดาร์อัตโนมัติ (ปัจจุบันเป็นฟังก์ชัน target tracking ตาม MSC.192(79)) | 1.3-B |
| Aspect | มุมที่มองเห็นเรืออีกลำวัดจากหัวเรือของเขา (red/green) | 1.3-B |
| Assertiveness | การกล้าแสดงความเห็น/ความกังวลอย่างสุภาพและชัดเจน | 1.2.2, 3.7 |
| Authority gradient | ช่องว่างอำนาจระหว่างผู้บังคับบัญชากับผู้ใต้บังคับบัญชา ถ้าชันเกินไปคนไม่กล้าพูด | 1.2.2, 3.7 |
| Azimuth | ทิศของเทห์ฟ้าที่วัดในแนวราบ ใช้หาความผิดของเข็มทิศ | 1.1.1, 1.1.5 |
